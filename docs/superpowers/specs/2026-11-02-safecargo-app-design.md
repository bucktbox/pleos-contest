# 세이프 카고 1차 제출 앱 — 설계서

- 작성: 2026-11-02 · 개발자
- 상태: 설계 완료 — 승인 대기
- 근거: PRD v1.0 · 화면정의서 v1.0 + 전달메모 · PRD 교차 검토(2026-11-02) · **SDK POC 검증결과(2026-11-02)**
- 범위: 11/14 제출용 1차 앱. 2차 PT 고도화(ISSUE-04)는 다루지 않는다.

## 1. 목적

차량 신호(기어 · 깜빡이 · 조향 · 착석)로 "카고 호위"를 판정하고, **정차 후** 언박싱 · 앰비언트 조명 · 리워드로 보상하는 Pleos Connect 앱을 만든다.
심사에서 보일 것은 **시연 영상 S1 한 바퀴**(적재 → 호위 → 정차 개봉)가 끊김 없이 돌고, release APK 가 에뮬레이터에 설치돼 같은 흐름이 재현되는 것이다.

### 성공 기준
1. 클린 에뮬레이터에서 S1(VC 스크립트)을 **3회 연속** 크래시 없이 완주 (NFR-STB-001)
2. P 정차 → 언박싱 화면까지 **1초 이내** (NFR-PER-001)
3. 주행 중 앱 터치 0, 텍스트 읽기 요구 0 (NFR-SAF-001)
4. 선언 권한 = 실제 사용 API 권한 (NFR-SEC-001)
5. 기준 창 2개(S-17 가로 1700×1184 · 세로 840×1184)에서 시안과 일치, 나머지 10개 창에서 레이아웃이 깨지지 않음 (Preview 확인)

### 하지 않는 것 (1차)
- 서버 · 로그인 · 실제 쿠폰/포인트 · 실제 제휴 (전부 Mock + 「예시」 표기)
- 감속 판정 (ISSUE-05 → C 안), 차속 API(`CAR_SPEED`) 사용
- 숏폼 (ISSUE-03)
- SC-08 기록 화면, 뱃지 · 칭호(FR-APP-010) — 시간이 남으면 추가

### 실패로 볼 것 (기술적으로 돌아가도)
- 주행 중 화면이 사용자의 시선 · 조작을 요구한다
- 앰비언트 조명이 원래 색으로 돌아오지 않은 채 남는다
- 「예시」 없이 금액 · 제휴명이 보인다, 실명이 드러난다

## 2. 결정 사항

### 2.1 POC 로 확정된 것 (변경 없음)
| 항목 | 결정 |
| :--- | :--- |
| 정차 판정 | **기어** `GEAR_PARK` = 정차, `GEAR_DRIVE`/`GEAR_REVERSE` = 주행, `NEUTRAL`/`UNKNOWN` = 불명(잠금) |
| 화면 게이트 | `CarUxRestrictions.isRequiresDistractionOptimization == false` 일 때만 정차 화면 조작 허용. 기어 P 와 **둘 다** 만족해야 언박싱 |
| 깜빡이 · 조향 · 착석 | Vehicle SDK 구독. 조향은 **부호 반전 보정**, 착석은 정차 시 `getCurrent…` 로 재확인 |
| 벨트 | 구독은 하되 시연은 착석 기준 (VC 조작 불가). VC 는 벨트를 전 좌석 `false` 로 계속 보내므로 `beltSignalTrusted`(기본 `false`)가 꺼져 있으면 벨트를 **불명**으로 취급 |
| 목적지 | 앱 선택 → `requestRoute`, 내비 설정 목적지는 `getDestinationInfo`/`onDestinationInfo` |
| TTS | `ON_DEVICE`. 리스너는 초기화 성공 뒤 등록 |
| 위치 | `FusedLocation.isSupported()` → `getLastKnownLocation` 1회 (POC: 지원 true, 받은 값의 나이 약 0.8초). 나이 `locationMaxAgeSec`(기본 60) 초과면 실패로 본다 |
| 조명 | 5개 영역 백업 → 등급 색 3초 → 원복. 권한 `CAR_LIGHTS` + `CONTROL_CAR_LIGHTS` |
| 권한 | `CAR_DRIVE` · `CAR_LIGHTS` · `CONTROL_CAR_LIGHTS` · `CAR_SEATS` · `NAVI_ROUTE` · `NAVI_ROUTE_SEARCH` · `TTS_SERVICE` · `FUSED_LOCATION` · `android.car.permission.CAR_DRIVING_STATE` (9개) |

### 2.3 개발자 판단 (설계에서 정함)
- **단일 모듈 Android 앱, Kotlin + Jetpack Compose.** 피그마 변수 · 컴포넌트를 그대로 옮기고, 12개 창을 `@Preview(device = "spec:…")` 로 확인하기 위함. XML 대비 반응형 분기가 단순하다.
- **DI 라이브러리 없음.** `Application` 이 엔진 · SDK 래퍼를 들고 화면은 구독만 한다. 1인 · 12일 일정에서 Hilt 설정 비용을 아낀다.
- **판정 엔진은 순수 Kotlin**(Android 의존 없음)으로 만들고 단위 테스트를 붙인다. SDK 래퍼가 신호를 `VehicleSignal` 이벤트로 바꿔 엔진에 넣는다 → 엔진은 VC 없이 테스트 가능.
- **앱 위치**: 지금은 이 저장소 `app/`(루트 Gradle 프로젝트)에서 개발한다. 제출 저장소는 ISSUE-02 결정 후 익명 계정으로 새로 만들어 소스만 옮긴다 (교차 검토 H9).
- **POC 코드는 가져오지 않는다.** 시그니처 · 순서 · 함정만 참고한다.
- **피그마**: 파일 「현대자동차 공모」(`4Mq81UW9aSEY7IwbUDvJND`) — 페이지 「시스템 가이드」 변수(Pretendard · accent `#4c8dff` · 배경 `#090b0f` · `size-touch-min` 76)와 「02 SC-01 로비」 프레임. **테마는 다크 하나**(시안이 다크), 라이트는 만들지 않는다. 터치 최소 76dp (Q-01 확정 시 변경). SC-01 외 화면은 시안이 오기 전까지 화면정의서 와이어프레임으로 만든다.
- **시연 도착 처리**: VC 속도로는 위치가 움직이지 않으므로, 시나리오 스크립트가 P 직전에 `adb emu geo fix` 로 에뮬레이터 위치를 스폰서 Mock 좌표로 옮긴다. 앱 로직은 실제와 같다 (P → 위치 1회 → 반경 비교).
- **반경 밖에서 「도착」**: 스폰서 카고도 개봉은 허용한다(상자는 항상 열림). 단 리워드는 **일반 리워드 + 「도착 인증 없음」**, 스폰서 쿠폰은 주지 않는다.
- **데일리 자동 적재**: 대기 상태에서 기어 D/R 이 되면 데일리 카고를 실는다. 개봉 중 재출발도 같다(결과 확정 → 완료 → 대기 → 데일리). 반복 시연을 위해 디버그 빌드에만 「기록 초기화」를 둔다.

## 3. 구조

```
            Virtual Console / 차량
                    │ (IPC 콜백, binder 스레드)
┌───────────────────▼────────────────────────────┐
│ sdk/  VehicleSource · NaviSource · TtsPlayer ·  │  ← Pleos SDK 래퍼 (Android 의존)
│       AmbientLight · LocationOnce · UxGate      │     콜백 → Flow 로 변환, 메인 스레드 전달
└───────────────────┬────────────────────────────┘
                    │ VehicleSignal (Gear / Turn / Steer / Seat / Ux)
┌───────────────────▼────────────────────────────┐
│ engine/  TripStateMachine · JudgeEngine         │  ← 순수 Kotlin, 단위 테스트
│          (JudgeConfig 주입)                      │     StateFlow<TripUiState> 하나만 내보냄
└───────────────────┬────────────────────────────┘
                    │ StateFlow
┌───────────────────▼────────────────────────────┐
│ ui/  CargoApp (Compose) — 상태로 화면 결정      │  ← 화면은 상태를 그리기만
│      SC-01 로비 · 02 목적지 · 03 호위 · 05 언박싱 │
│      · 06 리워드 · (07 랭킹)                     │
└───────────────────┬────────────────────────────┘
                    │
┌───────────────────▼────────────────────────────┐
│ data/  MockRepository (assets JSON)             │
│        TripStore (진행 중 상태 + 완료 결과 JSON) │
└─────────────────────────────────────────────────┘
```

- **엔진 수명 = 프로세스.** `SafeCargoApp : Application` 이 엔진과 SDK 래퍼를 만들고 `onCreate` 에서 시작한다. Activity 가 다시 만들어지거나 창 크기가 바뀌어도 상태는 엔진에 있다 (전달메모 「상태 보존」).
- 창이 가려진 상태(내비만 보임)에서도 콜백은 계속 받는다 — 프로세스가 살아 있는 한. **포그라운드 서비스는 1차에 쓰지 않는다** (추가 권한 · 심사 협의 부담). 프로세스가 죽으면 EX-08 복구로 처리한다. 실차에서 문제가 되면 2차에서 검토.

## 4. 상태 모델

```
            앱 시작
              │
        ┌─────▼─────┐  목적지 선택 / 내비 목적지 수신 / 데일리 자동
        │   대기     ├───────────────────────────────┐
        └───────────┘                                │
                                               ┌─────▼─────┐
                       ┌───────────────────────►  적재됨   │ (정차, 조작 가능)
                       │                       └─────┬─────┘
                       │                             │ 기어 D/R
                       │                       ┌─────▼─────┐
                       │                ┌──────►  호위 중   │ (조작 잠금)
                       │                │      └─────┬─────┘
                       │                │ 기어 D/R   │ 기어 P
                       │          ┌─────┴─────┐      │
                       │          │ 일시 정차  ◄──────┤ 도착 아님
                       │          └─────┬─────┘      │ 도착 맞음 (+UX 해제)
                       │                │ 「도착」   ┌─▼─────────┐
                       │                └───────────►   개봉    │
                       │                            └─────┬─────┘
                       │                                  │ 닫기
                       │                            ┌─────▼─────┐
                       └────────────────────────────┤   완료    │ → 결과 저장 → 대기
                                                    └───────────┘
```

| 전이 | 조건 | 비고 |
| :--- | :--- | :--- |
| 적재됨 → 호위 중 | 기어 D 또는 R | 카고 없이 주행 시작하면 데일리 카고 자동 적재 후 호위 (FR-APP-004) |
| 호위 중 → 판정 | 기어 P | **위치 1회** 조회 → 목적지 반경 안이면 개봉, 아니면 일시 정차 |
| 일시 정차 → 개봉 | 사용자가 「도착」 | 버튼은 **기어 P + UX 제한 해제**일 때만 활성. 데일리 카고는 항상 이 경로 |
| 일시 정차 → 호위 중 | 기어 D/R | 판정 계속 |
| 개봉 중 기어 D/R | 연출 · 소리 즉시 중단, 조명 즉시 원복, **결과는 이미 확정 → 중복 지급 없음** | 검토 Codex 인수조건 |
| 기어 N/UNKNOWN · SDK 단절 | 조작 잠금 유지, 전이 없음 | 검토 M7 |
| 위치 거부 · 실패 · 미지원 | 「도착 인증 없음」 표시 + 일반 리워드 (스폰서 쿠폰 대신) | EX-03, 검토 M3 |

- 위치는 **운행당 P 전환 시 1회**(일시 정차에서 「도착」 시 다시 1회 허용). 좌표는 비교 후 버린다.
- 앱이 화면에 없을 때 도착하면 앞으로 끌어오지 않고 개봉 대기 상태를 유지한다(SD-06). TTS 안내는 `drivingAudio` 와 무관하게 정차 상태라 허용.

## 5. 판정 규칙 (기본값 기준)

| 규칙 | 입력 | 판정 | 효과 |
| :--- | :--- | :--- | :--- |
| 선행 깜빡이 | 깜빡이 · 조향 | 깜빡이 켠 뒤 **같은 방향**으로 `|조향| ≥ turnAngleDeg` 발생 → 성공. 켠 뒤 `perfectSignalSec` 이상이면 퍼펙트 | +Key (퍼펙트 ×1.5). 운행당 `maxSignalBonusPerTrip` 회까지 |
| 무깜빡이 큰 조향 | 조향 | 깜빡이 없이 `|조향| ≥ turnAngleDeg` | `penaltyNoSignalTurn` (기본 0) — 횟수만 기록 |
| 부드러운 조향 | 조향 | 큰 조향 1회마다 최대 변화율 `≤ harshSteerDegPerSec` → +Key 소량 | 급조향은 `penaltyHarshSteer` (기본 0) |
| 패밀리 버프 | 착석 | 운전자 외 착석 ≥ `familyBuffMinPassengers` (벨트를 믿을 수 있으면 착석 좌석 전부 체결도 요구, 벨트 불명 · 미지원이면 착석만) | 최종 Key × `familyBuffMultiplier`. **벨트 불명 시 "전원 벨트 확인" 문구 금지** |
| 등급 | 최종 Key | `gradeThresholds` | 상자는 **항상** 열림 |

- 한 번의 조향은 한 번만 판정한다 (재판정 방지: 조향이 `turnAngleDeg/3` 아래로 돌아오면 다음 판정 준비).
- 깜빡이 OFF 후 `signalGraceSec`(기본 2초) 안의 조향까지 인정 — 회전 중 깜빡이 자동 해제 대응.
- 조향 콜백은 변화 없어도 약 3초마다 재전송된다(POC) → 같은 값은 무시.

- 터치 최소 76dp (피그마 변수), 색 · 글자 · 간격은 피그마 변수를 Compose 토큰으로 옮긴다.
- 피그마 시안이 없는 화면(SC-02 · 03 · 05 · 06)은 화면정의서 와이어프레임으로 먼저 만들고 시안이 오면 맞춘다.
- 조명 실패 · 미지원 시 화면 테두리 라이트로 대체 (FR-VH-012).

## 7. 데이터

- **Mock** (`assets/mock/*.json`): 스폰서 4곳(지자체 · 휴게소 · 카페 · 데일리) · 카고 3종+ · 쿠폰 · 포인트 · (랭킹). 좌표는 시연용 가상 좌표.
- **TripStore** (`files/` JSON 2개):
  - `active_trip.json` — 진행 중 카고(카고 id · 목적지 이름 · Key · 버프 · 판정 카운트 · 개봉 진행). 상태 바뀔 때마다 저장, 재시작 시 복구(EX-08). 개봉 완료 시 삭제.
  - `trips.json` — 완료 결과(등급 · Key · 버프 · 일자 · 목적지 이름 · 도착 인증 여부). **좌표 · 원시 신호 없음** (FR-DATA-003).
- 결과 저장은 **개봉 결과 확정 시점 1회** — 개봉 중 재출발 · 재시작으로 중복 지급되지 않게 결과 id 로 막는다.

## 8. 오류 처리

| 상황 | 처리 |
| :--- | :--- |
| 도메인 미지원 (`ERROR_NOT_SUPPORTED_*`, 실패 콜백) | 해당 규칙 · 연출만 끄고 루프 계속. 로비에 작은 안내 |
| Vehicle 초기화 직후 실패 | 500ms 간격 재시도 (POC 방식), 10회 실패 시 "차량 연결 안 됨" 상태 — 조작 잠금 |
| 조명 set 실패 · 부분 성공 | 성공한 영역만 원복, 화면 테두리 라이트로 대체 |
| 조명 원복 | 개봉 3초 후 · 개봉 중 재출발 · Activity `onStop` · 앱 종료 — **모든 경로**에서 백업값으로 |
| TTS 실패 | 음성 없이 진행 (EX-07) |
| 내비 실패 | 목적지는 앱 안에서만 유지, 안내 전달 실패 문구 |
