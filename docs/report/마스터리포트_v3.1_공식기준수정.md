### 1.2 공식 1차 서류심사 기준
공식 가이드(심사·시상 페이지)에 공개된 4개 필수 평가 항목입니다. **세부 배점은 공개되지 않습니다.**

> ⚠️ v3.0의 "창의성 50% / 실현 가능성 30% / 공감도 20%"는 **2026년 6월 부산모빌리티쇼 인스타그램 사전 이벤트(댓글 아이디어 공모)의 심사 기준**으로, 이번 공모전 기준이 아닙니다. "현대차그룹 저널 심사위원 인터뷰"도 출처가 확인되지 않아 삭제했습니다.

| 항목 | 공식 평가 요지 | 우리가 답해야 할 핵심 질문 |
| :--- | :--- | :--- |
| **차량특화성** | 모바일과 달리 차량 환경만의 가치를 제공하고, 주행·정차 맥락 및 차량 기능과 결합 | *"왜 스마트폰이 아니라 반드시 차량(Pleos Connect)이어야 하는가?"* — 차량 신호 조회(`get`/`callback`)와 하드웨어 제어(`set`)의 결합, 미러링 수준 앱은 불리 |
| **창의성** | 독창적·혁신적 아이디어, 운전자·동승자의 불편과 니즈가 명확하고 해결 방식이 분명 | *"누구의 어떤 불편한 순간을 어떻게 해결하는가?"* |
| **기술 활용성** | Pleos Playground의 SDK·API를 핵심 기능과 사용 경험에 적절히 활용 | *"공개된 SDK만으로 구현 가능한가?"* — 미공개 센서(카메라 원본, 생체 센서 등) 의존 금지, 제어 퍼미션은 App Market 사전 승인 범위 내 |
| **사업성** | 타깃이 명확하고 사용자 확보·지속 이용·확대 가능성 (**타깃 분석, 예상 MAU, Retention Rate, 서비스 확대 계획**) | *"얼마나 많은 사람이 계속 쓰는가?"* — v3.0에서 빠져 있던 항목, 접수양식 ⑥번에서 직접 요구 |

* **주행 안전(Zero-Distraction)**: 공식 항목은 아니지만 차량특화성·기술 활용성 평가에서 기본 전제로 보는 것이 안전합니다. 운전 중 화면 조작을 최소화하고 차량 상태에 따라 자동 동작하는 UX를 기본으로 합니다.
* **Gleo AI**: 공모전 공식 SDK 목록(Vehicle, NaviHelper, TextToSpeech, SpeechToText, FusedLocation)에는 포함되지 않습니다. App Schema는 Gleo 측 검토·승인 후 활성화되며, 에뮬레이터 지원 여부도 미확인입니다. → **필수가 아닌 확장 기능**으로 두고, 기본 진입은 버튼·STT로 설계합니다.

## PART 3. Pleos Connect SDK 및 외부·공공 API 상세 기술 명세

기획서의 설득력을 극대화하기 위해 아키텍처와 시나리오에 반드시 명시해야 할 **공식 SDK 모듈 및 외부 API 카탈로그**입니다.

### 3.1 Pleos Connect SDK (5대 핵심 모듈)

#### ① Vehicle SDK (`v2.3.2` / `Vehicle Service v2.3.21`)
* **동작 원리**: `Vehicle` 진입점 인스턴스에서 `getXxx()`로 도메인 객체를 획득한 뒤, `checkXXXCapabilities`(지원 여부 확인), `get`(현재 상태 조회), `set`(하드웨어 제어), `callback`(실시간 상태 변화 구독)을 비동기 IPC(`onComplete` / `onFailed`)로 처리합니다.

| 도메인명 (`getXxx()`) | 조회 가능 데이터 (`get` / `callback`) | 제어 가능 하드웨어 (`set`) | 기획 및 개발 핵심 활용 포인트 |
| :--- | :--- | :--- | :--- |
| **Brake** | 브레이크 페달 작동 여부, 주차 브레이크(P) 상태 | - | 급제동(Jerking) 감지, 정차(P단) 시점 트리거 |
| **CarInfo** | 차종, 제조사, 연식, **차량 외부 크기(전장/전폭/전고)** | - | 차체 물리 규격 맞춤형 주차장·진입로 필터링 |
| **Display** | 인포테인먼트 표시 단위(온도 등) 조회 | 표시 데이터 단위 설정 | 글로벌/사용자 맞춤 UI 단위 동기화 |
| **Door** | 도어 열림/닫힘 상태, 도어 잠금 상태 | **도어 잠금 / 해제 제어** | 승하차 감지, 도어 잠금 확인·잠금 (⚠️ 일반 잠금만 제공, **차일드락 제어는 없음**) |

| **Toll** | 하이패스(ETCS) 상태 및 음성 안내 음량 조회 | **하이패스 음성 안내 음량 제어** | **영유아 수면 또는 감성 몰입 모드 시 톨게이트 안내음 음소거(0)** |
| **TurnSignal** | 좌/우 방향지시등, 비상등 작동 상태 | - | 차선 변경 빈도 분석, 정차/위급 상황 트리거 |

#### ② NaviHelper SDK (`v3.0.5`) & FusedLocation SDK
* **핵심 기능**: 현재 정밀 GPS 위치 조회, 목적지/경유지(Waypoint) 설정·조회·취소, 경로 옵션 변경 및 재탐색 요청, 내비게이션 화면 호출, 실시간 주행 경로 이벤트 수신(`NaviHelperEventListener`).

#### ③ Gleo Interface (LLM Function Calling) & TTS / STT SDK
* **핵심 기능**: 앱 내에 JSON 규격의 `App Schema`와 `Callback Schema`를 정의해 등록하면, 운전자의 자연어 음성 명령을 Gleo AI가 해석하여 서드파티 앱의 함수를 직접 호출(`Gleo Action`)하고 그 실행 결과를 받아 음성으로 응답합니다.
* **⚠️ 제약 (공식 문서 기준)**:
  * 공모전 공식 SDK 목록은 **Vehicle, NaviHelper, TextToSpeech, SpeechToText, FusedLocation** 5종이며 Gleo Interface는 포함되지 않습니다.
  * 스키마는 `assets/schema.json`으로 넣고 Gleo 측에 전달해 **검토·승인을 받아야 활성화**됩니다. 에뮬레이터에서 테스트할 수 있는지는 문서에 없습니다(10/28 설명회 질문 대상).
  * → 기본 진입은 **화면 버튼 + SpeechToText SDK**, Gleo는 승인 후 확장 기능으로 설계합니다.
* **⚠️ 퍼미션**: Vehicle SDK의 조회(`CAR_*`)·제어(`CONTROL_CAR_*`) 퍼미션은 **Pleos App Market과 사전 협의·승인된 범위에서만** 사용할 수 있으며, 미승인 퍼미션을 쓰면 앱 심사를 통과하지 못합니다. 차종별 지원 여부는 `checkXXXCapabilities`로 확인합니다.

## PART 4. 전방위 브레인스토밍 16선 (기능형 + API 확장형 + 감성형)

단순 유틸리티를 넘어 **차량 제어 중심(5선)**, **외부 데이터 예측 제어 중심(6선)**, 그리고 현대차 고객의 정서적 만족감을 극대화하는 **감성·센서리(Emotional & Sensory) 중심(5선)**까지 총 16개의 후보군을 도출했습니다.

### [Track A] 차량 하드웨어 제어 & 실용 기능 중심 (5선)
1. **슬립가드 (SleepGuard - Basic)**: *"글레오야, 아기 잤어"* 한마디로 하이패스(`Toll`) 음소거, 앰비언트(`Light`) 최저 조도, 뒷좌석 창문/도어 잠금(`Window`/`Door`), 무풍 온도 유지(`HVAC`), 급브레이크 무음 코칭을 수행하는 영유아 수면 사수 시퀀서.
2. **핏파인더 (Fit-Finder)**: `CarInfo`의 차량 외부 크기(전장/전폭/전고)를 읽어 목적지 기계식 주차장 및 좁은 골목 진입 가능 여부를 판별하고 광폭 주차장으로 우회 안내하는 대형차·초보 운전자 전용 큐레이터.
3. **EV 닥터 & 리세일 세이버**: `EvBattery`, `Brake`, `DrivingMode`를 분석해 배터리 스트레스 지수를 관리하고, 급속 충전 중 시트(`Seat`) 릴랙스 제어 및 중고차 매각용 ‘Pleos 배터리 관리 인증서’를 발급하는 앱.
4. **카-오피스 포커스 (Car-Office Focus)**: 주행 중에는 음성(`STT`+`Gleo`)으로 회의록 요약 및 미팅 경유지를 세팅하고, 정차(`Brake` P단) 시 시트 포지션·화상회의용 주백색 조명(`Light`)·저소음 공조(`HVAC`)로 즉시 변환하는 이동형 오피스.
5. **에어로-센스 (Aero-Sense)**: 와이퍼(`Wiper`) 작동 시 창문 자동 닫기 및 사이드미러 열선(`SideMirror`) 가동, 장거리 크루즈(`DrivingMode`+`Odometer`) 주행 시 졸음 방지 통풍 시트·냉풍·시안 블루 조명을 가동하는 안전 케어.

### [Track B] 외부 맵 & 공공 API 융합 예측 제어 중심 (6선)
6. **슬립가드 지오 (SleepGuard Geo)**: [아이디어 1 확장] 행안부 **과속방지턱 API**·국토부 **터널 API**·심평원 **달빛어린이병원 API**를 결합. 방지턱 150m 전 앰비언트 점멸로 감속 유도, 터널 300m 전 창문 폐쇄로 소음 차폐, 아이 발열 시 야간 소아과 즉시 라우팅.
7. **클리어런스 프로 (Clearance Pro)**: [아이디어 2 확장] Tmap 통행제한 도로 API 및 전국 주차장 제원 공공데이터를 결합하여 루프박스 장착 SUV나 대형 세단(그랜저/아이오닉 9)의 층고·전폭 걸림 사고를 출발 전 차단.
8. **모션 캄 (Motion-Calm)**: 국토부 **고도/경사도(DEM) 및 도로 곡률 API**를 분석해 전방 와인딩(급커브) 및 정체 구간 진입 2분 전 실내 온도를 20℃로 낮추고(`HVAC`), 창문을 2cm 미세 개방(`Window`)하여 동승자 차멀미를 선제 예방.
9. **포우-파일럿 (Paw-Pilot)**: 한국관광공사 **반려동물 동반 TourAPI** 및 기상청 API 연동. 90분 주행 시 펫 놀이터 휴게소를 경유지로 추천하고, 정차 중 외기 일사량 연동 실내 정온(19~21℃) 유지 및 창문 잠금을 수행하는 한국형 펫 케어.
10. **차지 앤 다인 (Charge & Dine)**: 환경부 **실시간 충전기 출력(kW) API**와 `EvBattery` 잔량을 계산해 정확한 충전 소요 시간(예: 27분)을 산출하고, 해당 시간 내 다녀올 수 있는 브런치 카페나 사전 픽업 드라이브스루(DT)를 매칭.
11. **웨더 실드 (Weather-Shield)**: 기상청 **도로기상지수(블랙아이스/안개) API** 및 에어코리아 미세먼지 API 연동. 결빙 위험 교량 진입 전 핸들/미러 열선 및 성애 제거를 선제 가동하고 침수 위험 지하차도를 우회.

### [Track C] 감성(Emotional) & 센서리(Sensory) 경험 중심 신규 브레인스토밍 (5선)

기능적 문제 해결을 넘어, **"차를 타는 시간 자체를 위로와 설렘, 감각적 몰입의 공간으로 바꾸는"** 고감도 감성 아이디어입니다. 디자이너와 기획자의 역량을 시각·청각·촉각(공조/시트)으로 가장 아름답게 보여줄 수 있는 영역입니다.

#### 💡 아이디어 12. [퇴근길 감정 디톡스] **시프트-오프 (Shift-Off) : 업무 모드에서 일상으로 건너가는 ‘감정 전이(Transition) 리추얼’**
* **감성 타깃**: 격무에 시달린 뒤 차에 타서도 업무 생각과 스트레스를 떨치지 못한 채 집으로 돌아가는 직장인, 혹은 집에 도착해 주차장에서 바로 내리지 못하고 차 안에 멍하니 앉아 쉬는 현대인(‘카 힐링족’).
* **핵심 인사이트**: 직장인에게 퇴근길 차 안은 ‘회사(사회적 자아)’와 ‘집(본래의 나 또는 엄마/아빠)’ 사이를 이어주는 유일한 **독립된 전이 공간(Liminal Space)**입니다.
* **SDK & 외부 API 감성 시나리오**:
  1. **퇴근 리추얼 시작 (`Gleo Interface` + `FusedLocation`)**: 회사 근처에서 저녁 시간대 시동을 걸거나 *"글레오야, 오늘 진짜 힘들었다"*라고 말하면, Gleo가 잔잔한 위로의 멘트와 함께 ‘시프트-오프 모드’를 가동합니다.
  2. **바이오리듬 다운시프팅 제어 (`Vehicle SDK`)**:
     * 출발 직후에는 긴장된 근육을 이완시키기 위해 `Steeringwheel` 열선과 `Seat` 등/엉덩이 온열 기능을 은은하게 켜고, `Light`(앰비언트)를 노을빛 코랄 오렌지색으로 물들입니다.
     * 주행 중 과속이나 급브레이크(`Brake`)를 밟으면 *"오늘은 조금 천천히 가도 괜찮아요"*라는 부드러운 `TTS` 음성과 함께 앰비언트가 깊은 숲속의 그린 컬러로 호흡하듯 천천히 명멸(Breathing)하며 심박수 안정을 유도합니다.
  3. **‘주차장 10분 안식처’ 시퀀스 (`NaviHelper` + `Brake` P단)**: 집 주차장에 도착해 P단(`Brake`)을 넣으면 바로 시동을 끄라고 재촉하는 대신, *"집으로 올라가기 전, 온전한 나만의 5분을 가질까요?"*라고 묻고 `Seat`를 무중력 릴랙스 각도로 눕히며 오늘 하루 수고했다는 맞춤형 오디오 에세이를 재생합니다.

#### 💡 아이디어 13. [차량 데이터가 연주하는 앰비언트 사운드스케이프] **오토-소나타 (Auto-Sonata) : 주행 속도와 날씨, 풍경이 실시간 작곡하는 생성형 오디오**
* **감성 타깃**: 야간 드라이브, 비 오는 날의 드라이브를 즐기는 감성 운전자, 매번 똑같은 플레이리스트에 질린 아반떼/그랜저/아이오닉 오너.
* **핵심 인사이트**: 차는 끊임없이 움직이며 수많은 리듬(속도, 와이퍼 움직임, 회전, 기상 변화)을 만들어냅니다. 자동차 자체가 하나의 거대한 악기가 되어 세상에 단 하나뿐인 배경음악을 연주합니다.
* **SDK & 외부 API 감성 시나리오**:
  1. **주행 물리량의 음악적 치환 (`Odometer` + `DrivingMode` + `TurnSignal`)**:
     * 차량의 주행 속도와 기어 상태에 따라 로파이(Lo-Fi) 또는 시네마틱 재즈 비트의 BPM과 레이어가 실시간으로 변합니다. 정차 중(`Brake`)에는 잔잔한 피아노 독주만 흐르다가, 고속도로 크루즈(`DrivingMode`)에 진입하면 풍성한 신디사이저 패드 사운드가 더해집니다.
  2. **날씨와 와이퍼의 협주 (`Wiper` + 기상청 API + `Light`)**:
     * 비가 내려 `Wiper`가 작동하면, 와이퍼의 왕복 주기에 맞춰 어쿠스틱 기타 아르페지오나 빗소리 샘플링이 비트에 얹어집니다. 동시에 `Light` 앰비언트가 음악의 주파수( 파형)와 외부 날씨(비 오는 날의 딥블루, 맑은 밤의 퍼플)에 맞춰 실시간 오로라처럼 일렁입니다.
  3. **방해 없는 몰입 (`Toll`)**: 감성 드라이브 모드가 켜진 동안 톨게이트를 통과할 때 깨는 하이패스 기계음(`Toll`)은 자동으로 볼륨을 줄여 음악적 몰입이 깨지지 않게 보호합니다.

#### 💡 아이디어 14. [기억과 계절의 시공간 캡슐] **데자-드라이브 (Déjà-Drive) : 그날의 온도, 조명, 바람까지 복원하는 감성 블랙박스**

* **핵심 인사이트**: 사진은 시각만 남기지만, 인간이 기억을 가장 강렬하게 떠올리는 매개체는 **‘그날의 공기 온도, 빛의 색깔, 소리, 그리고 함께 나눈 대화’**라는 다감각적(Multi-Sensory) 맥락입니다.
* **SDK & 외부 API 감성 시나리오**:
  1. **감각의 스냅샷 저장 (`Gleo Interface` + `Vehicle SDK` 전체 조회)**:
     * 여행길 해안도로를 달리다 노을이 너무 아름다울 때 *"글레오야, 지금 이 순간 저장해 줘"*라고 말하면, 현재 GPS 좌표(`FusedLocation`), 외부 날씨(기상청 API), 차량 실내 설정 온도(`HVAC`), 앰비언트 라이트 컬러(`Light`), 창문이 열려 있던 정도(`Window`), 그리고 당시 차 안에서 나눈 15초간의 웃음소리(`STT`/오디오 녹음)를 하나의 **‘감각 캡슐(Sensory Capsule)’**로 패키징해 저장합니다.
  2. **시공간 감각 복원 (Sensory Replay)**:
     * 1년 뒤 우연히 같은 도로 반경 500m에 진입하거나, 도심 속에서 문득 그날이 그리워 캡슐을 열면, 차량이 **그날 그 순간과 완벽히 동일한 실내 온도(`HVAC` 제어), 동일한 앰비언트 조명 색(`Light` 제어), 동일한 창문 개방감(`Window` 제어)**을 물리적으로 재현하면서 그날 녹음된 음성과 음악을 들려줍니다. SDV만이 할 수 있는 궁극의 감성 타임머신입니다.

#### 💡 아이디어 15. [시간과 풍경의 농도를 쫓는 여정] **골든아워 체이서 (Golden-Hour Chaser) : 일몰·야경·은하수 정밀 조우 내비게이터**

  2. **감성적 완성도 (디자이너 어필)**: 단순히 소리를 끄는 것을 넘어, 차량의 주행 속도와 와이퍼 움직임을 잔잔한 자장가/백색소음으로 치환하는 **‘드라이빙 사운드스케이프(#13)’**와, 곤히 잠든 아이와 함께 달린 그날의 온도·조명·창밖 경로를 기록하는 **‘패밀리 슬립 다이어리(#14 감성 캡슐)’**를 UI/UX에 녹여내어 차가운 기술 앱이 아닌 **따뜻한 패밀리 브랜드 앱**으로 승화시킵니다.

### 💡 PM을 위한 시연 영상(가산점 필살기) 연출 팁
1차 서류 심사위원들은 수백 개의 기획서를 읽느라 지쳐 있습니다. 이때 **1분 30초짜리 시연 영상**의 첫 15초를 다음과 같이 구성하면 심사위원의 시선을 완벽히 사로잡을 수 있습니다.

* **화면 분할 구도 (Split-Screen)**:
  * **좌측 화면**: 디자이너가 아름답게 디자인한 `SleepGuard Pro` 인포테인먼트 앱 화면.
  * **우측 화면**: 개발자용 `Pleos Connect Virtual Console` (실제 차량 하드웨어 상태값을 보여주는 콘솔 창).
* **킬러 장면 연출**:
  1. 운전자가 화면의 ‘수면 모드’ 버튼을 누르거나 STT로 *"슬립가드 켜줘"*라고 말하는 순간 ➔ (⚠️ Gleo 음성은 에뮬레이터 지원·승인 여부 확인 후에만 사용) 우측 `Virtual Console`의 **Toll Volume이 `5`에서 `0`으로**, **Ambient Light Brightness가 `100`에서 `10`으로**, **Rear Window가 `Open`에서 `Closed`로**, **HVAC가 `Auto 23.5℃`로** 0.5초 만에 일제히 바뀌는 장면을 직관적으로 보여줍니다.
  2. 이어서 차량이 가상 경로상의 **과속방지턱 150m 전방**에 진입하자, 아무런 경고음 없이 좌측 화면 가장자리와 우측 `Ambient Light`가 부드러운 호박색으로 점멸하며 감속을 유도하는 장면을 보여주면 **"차량 제어 SDK와 공공 API를 완벽하게 이해하고 구현한 팀"**으로 만점을 받게 됩니다.
