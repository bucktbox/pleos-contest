- 대상: POC 영상 2개 (11/03 카톡) · PRD 리뷰 H3 · H4 · 택민 대리님 피드백
- 피그마: 「02 SC-01 로비」 아래쪽에 라이트 프레임 2개를 추가하고 문구를 고쳤습니다. 주행 · 언박싱은 피그마 시안이 아직 없어서 이 문서로 먼저 요청합니다.

## 1. 주행 화면 (D단)
| 지금 | 변경 |
| :--- | :--- |
| 열쇠 숫자가 주행 중에 0 → 45 → 100으로 실시간으로 올라감 | **주행 중에는 숫자를 숨기고**, 언박싱에서 공개 (주행 중 화면 변화를 최소화, PRD 리뷰 H3) |
| 상자가 가만히 있어 화면이 정지된 느낌 (택민 대리님) | **상자를 아주 천천히, 은은하게 흔드는 대기 루프 하나만** 둔다. 이벤트(깜빡이 · 조향)에 반응하지 않는다 |

상자 모션 사양 (잠정):
- 회전 ±2°, 위아래 4dp 정도, 한 주기 4초, ease-in-out, 무한 반복
- 깜빡임 · 크기 변화 · 색 변화 · 효과음은 없음
- 주행 상태 칩과 버프 칩은 지금처럼 고정 표시

## 2. 언박싱 「이번 호위」
- **「깜빡이 잊음」 칸을 삭제**합니다. 실수 횟수를 보여주면 감점처럼 보입니다 (PRD 리뷰 H4: 가점만 주기).
- 남는 칸은 잘한 것만: 깜빡이 먼저 · 부드러운 회전 · (벨트 확인)

## 3. 라이트 모드
- 피그마 Color 컬렉션에 Dark / Light 모드가 이미 있고, SC-01 화면은 변수 바인딩만으로 라이트 모드로 정상 전환됩니다.
- 앱의 `SC` 토큰도 같은 변수 이름에 라이트 값만 추가하면 됩니다. 라이트 값은 `gray/50` 배경, `gray/0` 카드, `gray/950` 글자, `blue/500` 강조입니다. 전체 값은 피그마 「01 시스템 가이드 (라이트)」에 있습니다.
- 시스템 다크 / 라이트 설정을 따르게 할지는 결정이 필요합니다.

- 11/03에 변수를 추가했습니다: `color/seatmap/body` (다크 gray/800, 라이트 blue/50 `#EEF4FF`), `color/seatmap/glass` (다크 gray/700, 라이트 blue/100 `#DCE7FF`).
- 좌석 맵은 테두리 선을 없애고 채운 차체 + 앞유리로 바꿨고, 카고 영역은 회색 박스를 없애고 바닥 그림자로 바꿨습니다.
