## 2. 권한 정리 (실측)

| 권한 | 쓰는 곳 |

## 3. 그 밖에 알게 된 것

- **맥(Apple Silicon)에서 동작한다.** 공식 GPU 요구사항은 NVIDIA/AMD 만 적혀 있지만, 맥용 arm64 이미지가 따로 있고 정상 부팅된다.
- **VC 는 에뮬레이터 안의 HTTP API**(포트 8088)다. 브라우저 세션 heartbeat(3초 timeout)를 보내면 스크립트로 기어 · 속도 · 조향 · 깜빡이 · 착석을 조작할 수 있다 → **시연 영상 장면을 같은 스크립트로 반복 재현 가능.**
- VC 조명 색 값: Cyan `#00e5ff` · Blue `#2979ff` · Purple `#aa00ff` · White `#ffffff`. 조명 읽기 값에는 alpha 가 없다(`0xffffff`).
- 경로 요청 직후 `onRouteStarted` 와 `onRouteEnded` 가 거의 동시에 한 번 같이 왔다 — 원인 미확인.
- 화면에 `distractionOptimized` 를 선언해 주행 중에도 로그를 봤다. 선언하지 않은 화면이 주행 중 어떻게 가려지는지는 확인하지 않았다.
