# PRD v1.0 검토 — Claude + Codex 교차 검토 (2026-11-02)

- 대상: `docs/prd/PRD_세이프카고_v1.0.md` (기획자 작성, 2026-10-29) + 다이어그램 · 미결 확인요청서 · 화면정의서 전달메모
- Codex 원문: `2026-11-02-codex-review-prd-v1.0.md` (읽기 전용, 독립 검토)
- Claude 가 Codex 지적을 직접 확인해 거른 결과. **Codex 지적 중 틀린 것은 없었다.** 판단이 갈린 것은 ISSUE-01 하나(4절).

## 1. 총평

**PRD 자체는 잘 만든 문서다.** 근거 자료(SRC)를 붙이고, 사실 · 잠정 · 제안을 구분하고, 미결을 ISSUE · AG · U 로 나눠 담당과 기한을 적었다. 보험사 삭제, 위치 1회 처리, 서버 제외, 상자는 항상 열림, 「예시」 표기 등 v4.7 검토 지적도 대부분 반영됐다.

**다만 제출 전에 고쳐야 할 것이 세 가지다.**
1. **기어 API 가 없다는 전제(AG-03)가 틀렸다** — 공식 AAR 에 있다. 이 전제 때문에 정차 판정이 불필요하게 복잡해졌다.
2. **주행 중 게임 피드백과 벌점**(게이지 · HP 감소 · 금 가는 소리 · 경고 TTS · 감속 평가 · 무결점 스트릭)이 공식 주행 안전 지침과 충돌할 소지가 크다.
3. **11/05 동결까지 Must 가 너무 많다** — 화면만 약 12일(전달메모 추정)인데 남은 개발일은 약 10일.

## 2. Claude 가 직접 확인한 사실

### 2.1 기어 API 는 있다 (AG-03 정정)
공식 저장소에서 `ai.pleos.playground:Vehicle:2.3.2` AAR 을 받아 클래스를 직접 열어 확인했다 (2026-11-02).

| 확인 항목 | 결과 |
| :--- | :--- |
| `Vehicle` 클래스 | `public final Gear getGear()` **있음** (다른 도메인 getter 와 나란히) |
| `api.Gear` 인터페이스 | `getCurrentGearSelectionState(onSuccess: (VehicleGear) -> Unit, onFailed: (Exception) -> Unit)`, `registerGearSelection(GearSelectionListener)`, `unregisterGearSelection(...)` |
| `GearSelectionListener` | `onSelected(VehicleGear)` |
| `VehicleGear` 값 | `GEAR_PARK` · `GEAR_DRIVE` · `GEAR_REVERSE` · `GEAR_NEUTRAL` · `GEAR_UNKNOWN` · `GEAR_1~9` |
| 내부 구현 | Pleos 전용 차량 속성 `VENDOR_GEAR_SELECTION` 사용 |
| 웹 문서 | Gear 도메인 누락 (SRC-04 가 본 19개 목록에 없음) |
| 미확인 | **필요 권한**(바이너리로는 확인 불가), `checkGear…Capabilities` 없음, 앱마켓 심사에서 문서에 없는 API 사용이 허용되는지 |

→ AG-03 은 "기어 API 없음"이 아니라 **"AAR 에 있음, 문서 누락 — 권한 · 심사 허용 · VC Gear 카드 연동을 POC 와 운영 문의로 확인"** 으로 바꿔야 한다. 되면 정차 = `GEAR_PARK` 로 단순해지고, 「P단 · D단」 표현도 살릴 수 있다. `CarUxRestrictionsManager` 는 정차 판정 소스가 아니라 **화면을 열어도 되는지 보는 별도 안전 게이트**로 함께 쓴다 (Codex 지적과 동일).

## 5. 제출 전 Top 5

1. **AG-03 정정** — 기어 API 있음(AAR 직접 확인). PRD · SRC-04 · DG-01/03 · 운영 문의문 수정.

3. **11/05 동결 범위 확정** — 랭킹 · 자동 목적지 수신 · 조명 · 감속은 POC · 정책 결과로 채택/제외, 실패 시 제외 조건 명시.

5. **익명 · 정합성 점검** — 이름 포함 경로 삭제, 제출 저장소 분리, 가상 보상 표시, release APK · 접근 · 서명 · CC 를 11/13 까지 확인 후 11/14 제출.
