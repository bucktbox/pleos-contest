**기존 1순위 ‘입구핀’은 내리겠습니다. 새 후보 중에는 ‘함께듣기’를 먼저 검증할 만합니다.** 조향각·P단 신호 미확인으로 감점한 것은 제 오류였습니다. 실측 목록에 조회·구독 메서드가 모두 있습니다. 파일은 수정하지 않았습니다.

아래 순정 기능은 공식 공개자료 기준입니다. **동일 기능을 찾지 못했다는 것이 부재의 증명은 아니므로, 새 후보의 독창성·리텐션·구현성은 추정**으로 표시합니다.

1. **기존 후보 재평가 — 각 2줄**

- **P단 게임:** 기아 커넥트 스토어에 이미 **아케이드 게임 8종**이 있습니다. 순정 게임의 조향각 입력 지원 여부는 **불확실**합니다. [기아 공식 가격표](https://www.kia.com/content/dam/kwp/kr/ko/vehicles/pdf/price/price_sorento.pdf)  
  **겹침 중~높음.** 기술 감점은 철회하되, ‘차에서 게임’보다 **핸들로 해야 재미있는 고유 규칙**이 필요합니다.

- **입구핀:** 순정 내비에 지도 지점 선택·위치 저장·등록 지점 재안내가 이미 있습니다. **입구별 학습·교정**까지 제공하는지는 **불확실**합니다. [현대 내비 설명서](https://ownersmanual.hyundai.com/ivi/PREM_GEN5/AVNT/FE/KOR/Korean/navigation004.html)  
  **겹침 높음.** 좌표 즐겨찾기를 넘어설 근거가 약하고, 기존 위치 저장형 설계는 이번 사생활 원칙과도 충돌합니다.

- **우리차 셔틀:** 순정 내비의 경유지 추가와 겹칩니다. **요일별 픽업 작업 관리·탑승 완료 후 다음 일정 진행**의 동일 제공 여부는 **불확실**합니다. [현대 내비 설명서](https://ownersmanual.hyundai.com/ivi/PREM_GEN5/AVNT/FE/KOR/Korean/navigation004.html)  
  **겹침 중간.** 목적지 묶음보다 ‘반복 픽업 진행 관리’가 차별점이지만, 저장 경로·동승자 이력 없는 설계로 바꿔야 합니다.

- **알아서 들르기:** 현대 순정에 **EV 경로 플래너**가 있습니다. 내연차의 연료 부족 연계 주유소 추천은 현행 차종별 범위가 **불확실**합니다. [현대 EV 설명서](https://ownersmanual.hyundai.com/ivi/ccNC/AVNT/KOR/Korean/EV.html)  
  **겹침 높음.** ‘잔량에 맞춰 보급 장소 경유’ 자체로는 약하며, 가격·대기시간 최적화까지 가면 외부 데이터 부담이 커집니다.

- **SleepGuard 축소판:** 순정 **후석 취침 모드**가 후석 오디오를 끄고 앞좌석 음량을 낮춥니다. 하이패스·조명 일괄 적용과 종료 복구까지 같은지는 **불확실**합니다. [현대 후석 취침 모드](https://ownersmanual.hyundai.com/ivi/DA_GEN2_V/AV/CAN/Korean/002_Features_quietmode.html)  
  **겹침 높음.** 하이패스 연동은 차이가 있지만, 심사위원에게 ‘취침 모드 확장 설정’으로 보일 위험이 큽니다.

- **챙겨:** 현대차그룹 **후석 승객 알림**은 하차 시 후석 확인을 유도합니다. 사용자별 물건 목록까지 관리하는 동일 기능은 **불확실**합니다. [현대차그룹 설명](https://www.hyundaimotorgroup.com/ko/amp/CONT0000000000000750)  
  **겹침 중~높음.** 물건별 체크리스트는 차별점이나, 기존 장소별 알림 설계는 위치 저장을 제거해야 합니다.

2. **새 아이디어 4개**

공통으로 내연·하이브리드·EV에서 같은 경험을 제공합니다. 다만 **동력원 공통과 모든 차량의 센서 지원은 별개**입니다. 착석 상태는 세션 중에만 사용하고, 위치·탑승 이력·대화는 저장하지 않습니다. 아래 데모는 개발자 1명·3주 범위로 제한한 구상입니다.

**A. 함께듣기 — “한 명이 잠깐 내려도, 이야기에서 뒤처지지 않는 공동 오디오 플레이어.”**

- **순간:** 커플이 추리물을 듣다가 휴게소에서 한 명만 내린다.
- **SDK:** `getCurrentSeatOccupancy`·`registerSeatOccupancy` + 기어 조회·구독. P단에서 참여 좌석이 비면 앱 콘텐츠를 정지하고, 복귀 후 확인하면 짧게 되감아 재개.
- **왜 차:** 폰 단독으로는 **실제 동승석의 비움·복귀와 P단을 함께 읽어 공동 청취를 관리할 수 없다.**
- **리텐션:** 주 2회 함께 타는 커플 → 다음 화 → 중간 하차 때 자동 보류 → 다음 동행에서 이어듣기.
- **데모 킬러 장면:** 운전자는 그대로인데 **조수석만 비자 재생이 멈추고**, 복귀 후 직전 문장부터 이어진다.
- **리스크:** 공동 청취 자동 보류의 동일 순정 기능은 **미확인**. 센서의 짐 오인식·좌석 지원 범위·콘텐츠 판권이 관건이며, 데모는 자체 제작 음원 1편과 앱 내부 재생만 구현.

**B. 깜빡먼저 — “초보가 방향지시등과 핸들을 조작한 순서를 확인하는 연습 앱.”**

- **순간:** 연수 후 “방향지시등을 너무 늦게 켰나?”가 기억나지 않는다.
- **SDK:** `getCurrentTurnSignalState`·`registerTurnSignalState` + `getCurrentSteeringWheelAngle`·`registerSteeringWheelAngle` + 기어.
- **왜 차:** 폰 센서만으로는 **방향지시등을 켠 시점과 실제 핸들 조작 시작 시점의 차이**를 직접 측정할 수 없다.
- **리텐션:** 초보·장롱면허 운전자 주 2회 연습 → 한 가지 습관 확인 → 다음 연습에서 개선 비교.
- **데모 킬러 장면:** 같은 조향 입력에 대해 **“조향 2초 전 점등 / 조향 후 점등”**이 P단 복기 화면에 나란히 나온다.
- **리스크:** 기존 운전습관 분석과 인접하지만 이 조작 순서 훈련의 동일 순정 기능은 **미확인**. 조향각으로 교차로·차선변경을 판정할 수 없으므로, 지정한 연습 과제의 관측값만 제시. 숙련 후 이탈 가능성도 큼.

**C. 같이탄값 — “어디서 탔는지 기록하지 않고, 함께 탄 구간만 비용을 나누는 계산기.”**

- **순간:** 정기 카풀에서 중간에 타거나 먼저 내리는 사람의 분담금을 매번 계산한다.
- **SDK:** 착석 감지 + `getCurrentDistanceDriven`·`registerDistanceDriven` + 기어. 사전 합의한 km당 비용을 현재 인원수로 분배.
- **왜 차:** 폰 단독으로는 **좌석의 승하차 변화와 차량 주행거리를 연결해 수동 입력 없이 분담액을 누적하기 어렵다.**
- **리텐션:** 주 3회 고정 카풀 → 합의 단가 재사용 → 매번 달라지는 동승 구간 자동 계산.
- **데모 킬러 장면:** 두 번째 동승석이 중간에 채워지자 **그 시점부터 분담 비율이 바뀌고**, 먼저 내린 좌석의 합계는 멈춘다.
- **리스크:** 동일 순정 기능은 **미확인**, 모바일 정산 앱은 경쟁 상대. 좌석별 합계만 메모리에서 계산하고 종료 시 폐기. 자리 이동·짐·거리 갱신 주기 때문에 실제 이용 전 검증 필수이며, 결제 기능은 제외.

**D. 핸들잼 — “주차한 차의 핸들을 30초 루프 악기로 바꾸는 음악 놀이터.”**

- **순간:** 매주 픽업을 기다리는 짧은 시간을 음악 만들기로 채운다.
- **SDK:** 조향각으로 음높이·필터 조절, 브레이크 페달 **작동 여부**로 박자 입력, 기어로 P단 이용 제한.
- **왜 차:** 폰 단독으로는 **실제 핸들과 페달을 입력 장치로 쓰는 연주 경험**을 제공할 수 없다.
- **리텐션:** 주 1회 대기 → 새 비트 과제 → 지난 루프 변주 → 음색 팩 추가.
- **데모 킬러 장면:** 작은 핸들 움직임이 즉시 선율이 되고, 페달 입력이 반복 비트에 쌓이다가 **P단 해제 즉시 종료**.
- **리스크:** 동일 순정 악기는 **미확인**. 보고서의 주행 기반 자동 작곡과 달리 직접 연주하지만, 차량 게임과의 인접성·입력 지연·정차 핸들 조작 부담·취향층 규모가 약점.

3. **기존 6개 + 신규 4개 비교**

각 항목 5점, **내부 추정**입니다. 공식 배점은 비공개이며, 합계는 동일 비중 비교용입니다. 순정 겹침·사생활 원칙은 합계보다 우선합니다.

추천 순서는 다음과 같습니다.

1. **함께듣기:** 문제와 해결을 가장 짧게 설명할 수 있고, 조회 신호만으로 핵심 데모가 성립합니다. 우선 검증할 것은 **“같이 듣다가 한 명만 내려서 불편했던 일이 반복되는가”**입니다.
2. **깜빡먼저:** 실측 SDK의 조향각·방향지시등을 기능의 중심에 씁니다. 순정 안전운전 점수와 구별되는 **구체적인 연습 도구**지만, 초보 졸업 후 리텐션은 약합니다.
3. **같이탄값:** 정기 카풀이라는 재사용 이유가 가장 분명합니다. 다만 **복수 좌석 착석 신호와 거리 갱신의 실용성**이 확인돼야 하므로 기술 검증을 먼저 해야 합니다.

제어 미승인 시 시뮬레이션 허용 결정을 반영해도, 이번 상위 3개는 **제어 없이 핵심 가치를 보여줄 수 있다는 점**이 유리합니다.
