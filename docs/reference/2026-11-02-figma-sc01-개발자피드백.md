# SC-01 로비 피그마 시안 — 개발자 피드백 (2026-11-02)

- 대상: 피그마 「현대자동차 공모」 › 02 SC-01 로비 (가로 L-R 1700×1184 / 세로 P-R 840×1184, 적재됨 상태)
- 대조 기준: PRD v1.0, 화면정의서 v1.0 + 전달메모, 공식 SDK 메서드 목록(`vehicle-sdk-2.3.2-methods.txt`), Virtual Console 가이드

## 총평
구조는 화면정의서와 잘 맞아서 이대로 개발 들어갈 수 있습니다.
가로는 좌측 레일, 세로는 상단 세그먼트이고, 상태 칩·버프·스트릭이 앱 바에 있습니다.
스폰서·목적지·카고에 「예시」 배지가 붙어 있고, 좌석 맵의 빈 좌석은 색이 아니라 점선 모양으로 구분됩니다.
컴포넌트(Status Chip · Nav Item · Key Card · Badge/Example)와 변수(색·간격·글자)가 정리돼 있어 Compose 로 옮기기 쉽습니다.

다만 **문구 3곳이 아직 확인 안 된 판정을 약속**하고 있고, **상태별 시안이 「적재됨」 하나뿐**이라 아래를 부탁드립니다.

## 1. 문구 수정 요청 (미결 항목과 충돌)

| 위치 | 지금 문구 | 문제 | 제안 |
| :--- | :--- | :--- | :--- |
| 열쇠 카드 「깜빡이 먼저」 | 켜고 나서 **차선 바꾸기** | SDK 조향각은 핸들이 아니라 **앞바퀴 각**이라 차선 변경은 각이 아주 작아 커브와 구분이 어렵습니다 (PRD AG-04). 차선 변경을 판정한다고 약속하게 됩니다 | 「돌기 전에 깜빡이 먼저」 또는 「켜고 나서 방향 바꾸기」 |
| 열쇠 카드 「부드럽게」 | 천천히 돌리고 **살살 멈추기** | 감속 판정 수단이 미정입니다 (ISSUE-05). 브레이크는 켜짐/꺼짐만 오고, 차속 API 가 없습니다. 그리고 "살살 멈추기"에 보상을 주면 **필요한 급제동을 망설이게 할 수 있어** 심사에서 안전 지적을 받을 수 있습니다 | ISSUE-05 결정 전까지 「핸들 천천히 돌리기」만 |
| 하단 상태 안내 | 달리는 동안엔 **소리로 알려줄게요** | 주행 중 효과음·TTS 허용 여부가 미회신입니다 (U-01). 공식 주행 안전 지침에 "게임 등 주의 분산 활동 유도 금지"가 있어 막힐 수 있습니다 | 「달리는 동안엔 화면을 안 봐도 돼요. 도착하면 상자가 열려요」 (U-01 회신 후 소리 문구 추가) |

> 「무결점 3일째」도 "한 번이라도 깎이면 실패" 느낌이라 벌점 인상을 줍니다. 「무사 배송 3일째」 정도를 제안합니다 (선택).

## 2. 추가로 필요한 상태 시안
지금은 「적재됨 · 3명 모두 벨트」 하나뿐이라, 개발할 때 아래 상태 화면을 추측해서 만들게 됩니다.

1. **패밀리 버프 상태 4가지**: ① 운전자 혼자 (Q-06: 혼자여도 버프가 켜지는지 결정 필요) ② 착석했지만 벨트 안 맨 좌석이 있음 ③ 차량이 벨트/뒷좌석 신호를 지원하지 않음 (EX-01) ④ 버프 켜짐 (현재 시안)
2. **카고가 아직 없는 첫 진입 / 목적지 미설정** 상태
3. **낮은 창 1개**: 세로 낮음 P-S (예: 628×855 또는 648×800). 12개 창 중 절반이 높이 900 미만인데, 지금 세로 시안은 1184 높이를 꽉 채웁니다. 어떤 블록을 줄이거나 스크롤할지 정해 주세요.

## 3. 시연 영상 관련 (Virtual Console 제약)
- Virtual Console 은 **좌석별 벨트 체결을 조작할 수 없습니다** (착석만 가능, 벨트는 경고등 카드뿐). 그래서 "3명 모두 벨트 OK" 장면은 콘솔로 재현이 안 됩니다. 시연에서는 착석만으로 버프를 보여 주고 자막으로 밝히거나, 그 장면을 빼야 합니다.
- 콘솔 조명 색은 Cyan · Blue · Purple · White 4가지뿐입니다. 시안의 「황금 카고」는 화면 연출로만 표현하고, 조명 색은 지원 색으로 매핑해야 합니다 (AG-02).

## 4. 개발 쪽에서 확인할 것 (기획 공유용)
- **기어 API 여부가 자료마다 다릅니다.** 공식 SDK 파일(AAR) 메서드 목록에는 `getGear` · `registerGearSelection` · `getCurrentGearSelectionState` 가 **있고**, PRD 근거 문서(웹 레퍼런스)에는 Gear 도메인이 없다고 돼 있습니다 (AG-03). POC 에서 실제로 컴파일·콜백을 확인해 알려드리겠습니다. 되면 「정차」 판정을 기어 P 로 할 수 있어 AG-03 이 단순해집니다.
- 터치 최소 크기 변수가 피그마에 `size-touch-min = 76` 으로 잡혀 있고, 전달메모는 64dp 잠정입니다. 개발은 76 으로 맞추겠습니다 (Q-01 확정 시 변경).
- 이 페이지에는 SC-01 만 있습니다. 다음으로 시연 경로 순서대로 SC-03 호위 → SC-05 언박싱을 먼저 받으면 좋겠습니다 (11/05 GUI 목표).
