## 4. 심사 — /guide/judging-awards

| 평가항목 | 주요 평가 내용 |
|---|---|
| 차량특화성 | 모바일 대비 차량 환경만의 가치, 주행·정차 맥락 및 차량 기능과의 결합 |
| 창의성 | 독창적이고 혁신적인 아이디어, 운전자·동승자의 Pain Point 와 Needs 정의 및 해결 방식 |
| 기술 활용성 | Pleos Playground SDK·API 를 핵심 기능과 사용 경험에 적절히 활용했는지 |
| 사업성 | 타깃 고객의 명확성, 사용자 확보와 지속 이용·확대 가능성 (예상 MAU, Retention Rate 등) |

- 「세부 배점은 공개하지 않습니다」. 가산점 = 개발 산출물. 2차 PT 기준은 추후 공지.
- Pleos App Market 탑재 준비 지원하나 「최종 입점이나 배포는 보장되지 않습니다」.

## 5. 개발 환경 — /guide/development · /faq

- 「Android API 28 이상, Gradle 8.0 이상, Java 또는 Kotlin」.
- 사용 가능 SDK: Vehicle · NaviHelper · TextToSpeech · SpeechToText · FusedLocation. 「각 SDK의 현재 제공 상태와 사용 조건은 SDK 문서 페이지에서 확인」.
- 「에뮬레이터 등 개발 도구로 검증」 언급. Virtual Console · 퍼미션 · 주행 중 제한 · 외부 서버 규정은 이 사이트에 없음 → Pleos 문서(SRC-04) 기준.
- 링크: document.pleos.ai/docs/pleos-only/connect-sdk-pleos/ · …/tutorial/vehicle-sdk · /api-reference/connect-sdk-pleos · …/setup-connect-sdk-emulator · pleos.ai/playground
