## 앱 개발자 당부

**보상 · 토큰**

1. 보상 추첨은 **언박싱 연출이 시작될 때 끝내고 바로 저장**합니다. 연출 중 주행으로 바뀌어도 결과가 남아야 합니다. 보너스 게임도 같습니다 — 토큰 차감 · 추첨 · 저장 → 연출 순서(EX-11).
2. 보상함(`WalletItem`)과 토큰 원장(`TokenLedger`)은 기기 안에 저장하고 재시작 후에도 유지합니다(FR-DATA-004). 토큰 잔액은 원장의 합으로 계산해 두 값이 어긋나지 않게 해 주세요.
3. 쿠폰 상태는 **한 방향**입니다: 사용 가능 → 사용 완료 / 사용 가능 → 사용 불가. 되돌리기 없음(PRD 5.2.1). 유효기간이 지난 쿠폰은 앱 실행 · 보상함 진입 때 사용 불가(기간 만료)로 옮깁니다.
4. 페이백 토큰은 쿠폰 1장당 **1회만** 줍니다. 사용 완료 처리를 두 번 눌러도 한 번만 반영되게 해 주세요.
5. 쿠폰 사용 확인 창이 열린 채 주행으로 바뀌면 창을 닫고 **상태를 바꾸지 않습니다**(EX-10).
6. 시연용 초기값 플래그를 둡니다 — 쿠폰 4장(사용 가능 2 · 사용 완료 1 · 사용 불가 1) + 토큰 7(FR-DATA-005). 기본은 꺼짐, 시연 빌드에서만 켭니다. 시연 S3 에서는 레어 + 꽝이 나오도록 추첨 결과 고정도 이 플래그로 묶어 주세요(ISSUE-07 권고).

**거친 운전 감지 · 모션**

- 흔들림은 기존 조향 변화율 판정(제2열쇠)을 그대로 씁니다. 급가속 · 급정거는 **차속**이 필요합니다. 11/02 POC에서 AAOS `PERF_VEHICLE_SPEED` 가 에뮬레이터에서 동작한 것은 확인했지만, `CAR_SPEED` 권한의 심사 허용 여부는 모릅니다(AG-06).
- 잠정 기준: 급가속 +3.0 m/s² 이상 · 급정거 −3.5 m/s² 이하, 1초 창 평균(JudgeConfig). 차속은 저장하지 않고 메모리에서만 씁니다.
- 급가속 · 급정거는 **모션만** 냅니다. Key · HP · 등급을 바꾸지 않습니다.
- 차속을 못 쓰면(미지원 · 권한 거부) 흔들림 모션만 남기고, 정차 화면 지원 배너에 「급가속 · 급정거 표시 꺼짐」을 띄웁니다(EX-09).
- 같은 종류 모션은 10초 쿨다운. 모션 재생 중에는 대기 루프를 멈췄다가 이어서 재생합니다(SD-13). 창이 바뀌어도 모션이 두 번 재생되면 안 됩니다.
- VC 스크립트(`scripts/s1-demo.sh` 처럼)로 **S3 장면 — 급가속 → 깜빡이 없는 급조향 → 급정거 → 정차** — 을 반복 재현할 수 있게 해 주세요. 시연 영상 촬영에 그대로 씁니다.

## 디자이너 당부

**거친 운전 모션 (SC-03 08)**

- 3종 (11/11 완화): 흔들림 = 바닥 모서리를 딛고 좌우 ±12° 까딱, 감쇠 1초 / 급가속 = 뒤로 12dp 밀리며 5° 기움 → 되튕김 0.9초 / 급정거 = 앞으로 12dp 쏠리며 5° 기움 → 되튕김 0.9초. 화면정의서 SC-03 08 에 움직이는 미리보기가 있습니다.
- **금지**: 점멸 · 색 변화 · 크기 확대 · 효과음 · 글자. 모션은 카고 아이콘 밖으로 번지지 않습니다(NFR-SAF-002).
- 11/03 요청서의 대기 루프(±2° · 4초)와 **별도 레이어**로 만들어 주세요. 두 모션이 겹쳐 진폭이 커지면 안 됩니다.
- 11/03 요청서에는 「주행 중 상자는 이벤트에 반응하지 않는다」고 적었는데, 이번 피드백과 충돌합니다. 거친 운전 3종만 예외로 두는 안으로 그렸고, 11/10에 확정합니다(ISSUE-08).

**보상 화면 (SC-06 · 09 · 10 · 11)**

- 쿠폰 상태는 **색 + 아이콘 + 글자** 세 가지로 함께 표시합니다: ✓ 사용 가능(초록 · 체크 원) / ◉ 사용 완료(회색 · 도장) / ⊘ 사용 불가(빨강 테두리 · 사선 원 + 사유). 사용 완료 · 불가 카드는 55% 흐리게 하되 글자 대비 4.5:1 이상(SD-11).
- 사용 가이드 info box는 **컴포넌트 하나**로 SC-06 · 09 · 10 에서 같이 씁니다. 펼침(5단계)과 접힘(한 줄 「쿠폰은 이렇게 써요 ›」) 두 상태가 필요합니다(SD-12).
- 꽝 카드에는 「꽝」「실패」를 쓰지 않습니다 — 「아쉬운 상자 · 비어 있었어요」. 운전 실수와 연결하는 문구도 쓰지 않습니다.
- 보너스 상자는 카고 상자와 **다르게** 생겨야 합니다. 연출은 2초 이내, 실내 조명 · 테두리 라이트는 쓰지 않습니다.
- 토큰 아이콘(🪙 자리) 1종, 보너스 상자 Lottie 1종, 빈 상자 그림 1종이 새로 필요합니다.
- 가장 좁은 창(628dp)에서 내비 4칸 · 상태 탭 3칸 · 쿠폰 항목의 남은 일수 · 사유가 잘리지 않는지 봐 주세요.
